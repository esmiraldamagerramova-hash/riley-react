# Riley (React + TS + Tailwind)

Vite + React + TypeScript + Tailwind версия лендинга.

## Важно про картинки (Netlify-ready)

Чтобы картинки работали и локально, и на Netlify, они должны лежать внутри проекта в:

- `riley-react/public/assets/images/*`
- `riley-react/public/assets/icons/*`

А в коде ссылки должны быть абсолютные от корня сайта:

- `/assets/images/...`
- `/assets/icons/...`
